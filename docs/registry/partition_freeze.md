# Stage 13 Partition Freeze

Date: 2026-07-03

This freeze covers only the first controlled execution cycle. Wave 0 and Wave 1A
are governance, evidence-stabilization, software-audit, and human-validation
preparation work. They do not authorize confirmatory experiments.

No Wave 2-4 GPU or confirmatory job is approved by this file. Any such run needs
explicit PI approval, a completed experiment card, and a recorded partition
assignment before submission.

Historical Stage 6-12 outputs remain preserved but are not paper-eligible merely
because they exist on disk. They must be linked to raw artifacts, registry rows,
and discovery/confirmation status.
