### J14.6-001 · 2026-10-16T17:40 · decision
kind: decision
**What:** Build a typed, proof-carrying generator in `src/physmon/benchmark/v2/`: `dimensions.py` (a dimensional
checker over sympy expressions), `graph.py` (typed nodes and a DAG), `certify.py` (eleven checks, a proof object and a
mutation harness), `design.py` (eleven predeclared factor cells, rendering, identity), `library.py` (ten structures).
**Why:** B3.2 asks for a typed executable graph with units, frames, sign conventions, provenance, a solver program and a
proof object, verified by independent routes and by mutation. The Stage 13 certificates recorded that no dimensional
checker existed (`unsupported_no_dimensional_checker`); this stage supplies one.
**Design choices:**
- Nuisance quantities are never graph nodes. They appear only in the rendered text, and the certificate rejects any graph
  in which the target depends on the nuisance symbol (a cue leaking into the equation).
- Every structure carries an independently coded solver (a 3x3 linear system, ODE integration with event detection, a
  momentum-and-energy quadratic, nodal analysis, a bracketing root finder, charge-and-loop linear equations). Agreement
  between the graph's closed form and that route is a real check, not two outputs of one generator (B3.2).
- Prompts avoid incidental numerals, so every numeral in a rendered prompt can be tied to a graph node (a certificate
  check that fails on any stray number).
**Alternatives considered:** extending the v1 YAML templates (rejected: no typed nodes, no independent solver); a
general natural-language generator (rejected: out of scope, and the English needs human review anyway).

### J14.6-003 · 2026-10-16T18:00 · observation
kind: observation
**What [V]:** The 155 v1 families contain only **31 distinct renaming-invariant equation programs** (the largest is shared by
44 templates), although `governing_law` has 104 distinct labels. Law labels overstate the number of independent symbolic
structures. This bears on v2 §8.1 (the independent unit is the structure, p.41) and on P2.4's warning against counting
paraphrases as independent (p.19).
**Caveat:** the hash is of the governing equation only (symbols renamed by sorted first appearance), not of the physical
setting, so two families with the same algebra in different settings count as one program here. It is a lower bound on
distinct programs and an upper bound on equation-level overlap.

### J14.6-004 · 2026-10-16T18:20 · observation
kind: observation
**What [V]:** The certifier caught two design flaws in my own structures before any data was written, which is the reason to
have it:
1. S03: the relevant edit (first mass x 0.8) fell outside the structure's admissible domain. Fixed by using x 1.25.
2. S09 originally asked for the final temperature (about 301 K). On an absolute scale no sensible edit moves the answer by
   the 5% minimum for a relevant edit (the largest was under 2%). The target is now the water's temperature rise
   (about 8.2 K), which responds to every governing input (a 1.5x change in the block mass moves it by 43%).
Also found and fixed: a node named `I` is read by sympy as the imaginary unit (and `E` as Euler's number), so expressions are
parsed with an explicit symbol table; the one-line RK4 loops were too slow and are replaced by event-driven ODE integration.

### J14.6-005 · 2026-10-16T18:40 · observation
kind: observation
**What [V]:** The mutation harness found a flaw in a mutator, not in the certifier. The first "divisor domain includes zero"
mutator chose `C1` in `C1*C2/(C1 + C2)` and `m2` in a weighted average: those inputs appear only inside a sum in the
denominator, so a domain reaching zero is not a singularity and the mutant was not a real defect (it escaped, correctly).
The mutator now picks only inputs that are multiplicative factors of a denominator (two structures qualify: S06 and S10). The
certifier was not changed. Final result: 95 mutants (75 planted defects from 9 mutators and 20 equivalent rewrites from 2; the divisor and
dropped-assumption mutators apply to only some structures), 0 defects uncaught, 0 equivalent rewrites rejected, every defect failing
for an intended reason.

**What:** The eleven factor cells and their bands are fixed in `design.py` before any model sees them: no-cue anchor;
non-numeric extra sentence; unrelated numeric metadata; non-governing same-unit quantity at near (within 1%, with high and

convertible unit). Each carries its reason.
**Not done here (later, after the core signal, B3.4):** placement and position variants, repeated mentions, paraphrase.
Cue position is fixed at "after the context".
