### J14.16-001 · 2026-10-18 · decision
kind: decision
**What:** Plan the version of X03 that the card names: a stratified sample of the original families, both primary models, paired wrapper variants. Stage 14.10 ran it on the ten v2 structures instead (J14.10-001).
**Sampling rule, frozen before any score exists [V]:** 60 of the 135 families of the Stage 14.4 cohort, stratified by cue type and domain; every non-empty stratum gets at least one family and the rest are allocated in proportion by largest remainder; a seeded draw (seed 42). Result: frame rendering 4 (electrostatics 1, mechanics 3), irrelevant variable 16 (5, 9, 2), nongoverning distractor 40 (11, 24, 5). The card's 140 is 135 here because five families have no stored behaviour record (Stage 14.4).
**Wrappers:** four of the Stage 14.3 contract (`answer_line`, `plain`, `boxed`, `json`), within the card's 4 to 6.
**Design [V]:** a legacy family has four renderings and each carries a cue: there is no no-cue prompt, so the anchor-matched design of the v2 analyses is not available. Instead the plan builds a candidate matrix inside each family: for every rendering v the gold answer, and for every rendering u the cue numeral of u written as an answer with the target unit, so the same string is scored where it is in the prompt (u = v, the diagonal) and where it is normally not (u different from v). A candidate numeral that also appears in a foreign prompt as a relevant input is flagged (204 per model). Families whose cue is not a number (a colour, a word, a unit rendering; 19 of 155 families) list the gold only. Legacy conventions are kept: the unit string as stored (for example `m/s^2`), the value text as stored.
**Limits stated before the run:** the diagonal-versus-off-diagonal contrast compares the same string across prompts that differ in more than the cue numeral (the cue value changes the cue sentence, and sometimes the relation to the problem); there is no clean absent condition; legacy renderings are a population of Phase-I families, not v2 structures.
**Tests [V]:** `test_legacy_x03_s156.py` 7 passed (allocation, the real sample, answer parsing, a complete candidate matrix, diagonal flags and foreign numerals, stored units, directory refusal). A first run of the tests found that 19 families have a non-numeric cue value; the planner now lists their gold only.

### J14.16-003 · 2026-10-18 · decision
kind: decision
**Frozen analysis, decided before any legacy score exists:**
1. **Within-string presence effect.** For each family, wrapper, model and cue candidate u (a numeral cue), the effect is the log-probability of the candidate string under its own rendering (u = v, the diagonal) minus the mean log-probability of the same string under the renderings v that differ from u and in which the numeral does not appear (the off-diagonal cells flagged `candidate_numeral_in_prompt` false). A candidate with no such off-diagonal cell is NOT_EVALUATED. Effects are averaged over the candidates of a family.
2. **Unit of analysis and interval:** the Stage 14.4 template cluster, not the family (families in one cluster are not independent); family values are averaged within a cluster; cluster bootstrap (2,000 resamples, seed 42) of the mean across clusters. Reported for all numeral-cue families and separately for the two cue types (nongoverning distractor, irrelevant variable).
3. **Wrapper interaction:** per cluster, the effect under a wrapper minus the effect under `answer_line`, summarised by the same bootstrap. **Dominance:** the interval excludes zero and the absolute difference is at least half of the absolute `answer_line` effect. **Invariance:** no difference interval excludes zero (no detectable wrapper dependence, not equivalence).
4. **D_lp:** per family and wrapper, the range of the gold log-probability across the four renderings, summarised by cluster, with the wrapper-minus-`answer_line` difference.
5. Not evaluated: any family whose cue is not numeric (gold only), and any record that is not OK. No p-values; descriptive; the legacy data role is exploratory.
**Reading limits stated now:** the diagonal-versus-off-diagonal contrast compares one string across prompts that differ in the whole cue sentence, so it is a presence effect with a looser control than the v2 anchor design; it is read against the dtype noise floor of J14.9 (0.1 to 0.3 nats), not as an anchor-matched shift.
