### J14.1-004 · 2026-10-16T09:55 · decision
kind: decision
**What:** Independent recomputation lives in `src/physmon/governance/recompute.py` (numpy only): tie-aware
AUROC, average precision, Brier, ECE, FNR@FPR, Pearson, the paired family-level bootstrap, both legacy
`S_lp` forms, and a "matches at the reported precision" comparison. It does not import
`physmon.probing.metrics`.
**Why:** X01's controls are "independent implementation, no circular calculations from summary tables"
(p.39). If the project's scikit-learn-based metrics and an independent implementation agree on committed
predictions, the reported numbers do not depend on a metric bug.
**Check [V]:** `tests/v2/test_recompute_v2.py` compares the two implementations on random inputs with ties
(sizes 12, 40, 135) to 1e-12 for AUROC, AUPRC, Brier, ECE and FNR@FPR, and shows the paired bootstrap
reproduces the project's interval exactly (same generator, same draw order, same one-class skip rule).
**Alternatives considered:** Calling `physmon.probing.metrics` (rejected: circular); adding scipy ranking
(rejected: not needed).

### J14.1-005 · 2026-10-16T10:00 · decision
kind: decision
**What:** Ledger rows may carry a `components` list (one entry per reported number or claim). The row label
is derived as the most conservative component outcome (`verified` < `different_but_explained` <
`not_enough_source_data` < `unreproducible`). A verified or explained row becomes `evidence_status=exploratory`
(legacy data, still exploratory); an unverified row, or any row whose `observed_rows` is 0, stays
`NOT_EVALUATED`. Nothing becomes `confirmatory` or paper-eligible.
**Why:** A single "verified" label on a row that mixes reproducible and missing values would hide the gap
(audit alert C, p.5). Component-level outcomes keep the evidence for each number visible.
**Files touched:** `src/physmon/governance/v2_contract.py` (`LABEL_SEVERITY`, `worst_label`, component
checks), `tests/v2/test_claim_ledger_v2.py` (two new tests).
**Known limit:** Row P1L-08 mixes the monitor-minus-entropy interval (reproducible) with the
combined-plus-hidden gain. The out-of-fold predictions of the combined-plus-hidden model were not committed
(only the summary), so that gain cannot be recomputed without re-running a script that overwrites tracked
results. That component is therefore `not_enough_source_data` and the row inherits that label.
