### J14.19-001 · 2026-10-26 · decision
kind: decision
**What:** On 2026-10-26 the user instructed: build a dataset of at least 200 samples, each with a gold trace that contains not only the gold answer but the perfect approach to solving the problem; use thinking models that can answer correctly, and then measure sensitivity to distractors; "override the physicist checking part"; deploy specialised agents (one for classical mechanics, one for quantum, and so on) that make the problems, add a verifier agent, and include a gold thinking trace that is a step-by-step solving technique and not a model's text.
**Decisions taken [I]:**
1. **The human physicist review is replaced by agent verification, by the user's instruction, and the category says so.** Every new item carries the framework's `UNREVIEWED` admission category (the certifier's meaning: no human expert has reviewed it) plus an `agent_verification` record: author agent, blind solver agent, plan reviewer agent, and the outcome. No document of this stage may call these items expert-reviewed, physicist-confirmed or validated by experts, and the Phase-I and v2 claims about independent review stay NOT_EVALUATED. The user's earlier one-reviewer walkthrough of S01 to S20 is unchanged; S21 to S30 had none, and this stage's agent checks stand in for it by the user's decision.
2. **A gold trace is generated from the typed graph, not written as free text.** The author of a structure supplies, for each computed node, the NAMED principle that produces it and why it applies (a `Plan`, with an approach sentence and a sanity check); `render_trace` evaluates the givens, the symbolic relation, the numeric substitution, the result and the unit from the graph, so the trace's numbers cannot disagree with the graph, and its last value is checked against the structure's independent solver. The trace is therefore a solving technique, not text produced by a model while answering.
3. **Specialised domain agents** author new structures in their own module (`lib_<domain>.py`: structures, plans, difficulty labels): classical mechanics, electromagnetism and circuits, thermodynamics, optics and waves, quantum mechanics, modern physics (relativity, nuclear), fluids and continuum. Each also writes plans for the existing structures of its domain (S01 to S30). New structures need at least four numeric instantiations each, so that about 50 new structures give about 200 samples and the 30 existing ones add 60.
4. **A verification chain per domain, all by different agents from the author:** a blind solver that sees only the problem text and the answer unit (no gold, no trace); a plan reviewer that runs the numeric comparison, derives disagreements independently, checks every principle and wording in the rendered trace, and rules on the problem's well-posedness; one repair round by an author agent; and a second blind check of every repaired item.
**Limits stated before any item exists [I]:** agent-written physics can be wrong in ways that agent checks share (the same model family, the same blind spots); numeric agreement of the gold with an independent blind solve is evidence of arithmetic and formula correctness, not of wording clarity or modelling choices; difficulty labels are the author agent's judgement; thirty to eighty structures are still clusters, so the effective sample size for any structure-level statement is the number of structures, not the number of instantiations.
**Scope:** CPU and agents only; no GPU job, no download, no Slurm action in this step. The runs of reasoning models on the dataset come after it exists and need the user's acceptance of each exact command.
