### J14.15-001 · 2026-10-18 · decision
kind: decision
**What:** Add ten more typed, proof-carrying structures (S11 to S20), taking the count from 10 to 20 of the 40 to 60 that B6.1 asks for. Laws: braking distance with locked wheels, maximum speed on a flat curve, small-amplitude pendulum period, power of a constant-speed lift, power of two parallel resistors, RL current rise, heat flow through a two-layer wall, work of an isothermal expansion, range of a projectile on level ground, thin-lens image distance.
**Why this choice:** the first batch was too hard for a 7 to 8 B model without reasoning (J14.7-023). These laws are shorter chains (one to three steps), so a model with reasoning has a chance of solving them, while each is a new renaming-invariant equation program. They cover four domains (mechanics, circuits, thermodynamics, optics).
**How it is built [V]:** the same pattern as Stage 14.6: a typed graph with units and assumptions, two numeric instantiations, a relevant edit, and an independently coded solver per structure (an ODE with an event for braking, pendulum, RL and range; a bracketing root finder for the curve speed and the lens; a linear system for the wall; adaptive quadrature for the isothermal work and the lift). Four units were added to the dimension registry (`H`, `mH`, `K/W`, `m^3`, `L`).
**Bug found and fixed in my own work [V]:** the first certification run failed for eight structures because I gave the solver input count wrongly (the number after the solver in `Structure(...)` is the count of input nodes); the certifier reported it as `solver expects 4 inputs but the graph has N`, and fixing the counts gave 10 of 10 certified. This is the certifier working, not a physics finding.
**Alternatives considered:** a constant-latent-heat ice-and-water mixing structure and a free-fall impact speed; dropped because the first needed several new constants and units and the second has the same program as a v1 template (`sqrt(2*g*h)`), which the generator would reject.
