# Stage 13 Validator Qualification Test

Answer each item without looking at model outputs or probe predictions.

1. A prompt asks for the acceleration of block A. It includes an unconnected block B with a different mass. Is block B's mass relevant to block A's acceleration if no interaction is stated?

2. A prompt asks for kinetic energy and includes the object's color. Is color relevant to the numerical kinetic energy?

3. A prompt asks for a value in SI units but gives an equivalent value in rpm. What should a validator check before accepting the family?

4. If a solver certificate is missing but the answer looks plausible, should the validator mark the answer as certified?

5. If the cue sentence is ambiguous and could change the physical system, what label should be used for cue irrelevance?
